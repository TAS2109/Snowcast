# Snowcast

## データ確認ページ

予報の計算（雪判別・統合）に入る前の「元データ」を、データ源ごとに1つずつ地図・グラフ・表で目視確認できます。

- GitHub Pages: `https://<ユーザー名>.github.io/<リポジトリ名>/inspect.html`（トップ画面の「データ確認」ボタンからも開けます）
- Flask版: `/inspect`

| タブ | 内容 |
|---|---|
| 概要 | 全データ源の取得状況（成功/失敗・取得時刻・期間・含まれる要素）と、予報地点・周辺アメダス・各モデル格子点の地図 |
| 確定論モデル | 14モデルを1つずつ。格子点の地図、9要素の時系列、時間別の表、CSV。「全モデル重ね」で同じ要素を並べて比較 |
| アンサンブル | 7モデルを1つずつ。全メンバーの線＋中央値と10〜90%帯、時刻を選んだメンバーのばらつき（ヒストグラム）、統計表、CSV（統計／全メンバー） |
| アメダス甲府 | 実測の時系列、雪判定の帯、表、CSV |
| 周辺アメダス | 地図（雪あり/なしで色分け）、気温・積雪深のグラフ、並べ替えできる表、CSV |
| 公式予報 / 警報・注意報 | 気象庁の天気・降水確率・気温・週間予報、発表中の警報・注意報 |
| 雨雲レーダー | 気象庁の降水ナウキャスト（再生ボタン付き） |

データは `data/raw.json`（Flask版は `/api/raw`）にまとめて出力されます。

## マップタブ

背景（淡色・標準・航空写真・陰影起伏）を1つ選び、重ねる情報をチェックボックスで切り替えます（選択はブラウザに記憶されます）。

- 雨雲レーダー（実況＋1時間先・再生ボタン付き）
- アメダス: 雪の有無 / 気温 / 積雪深
- 予報地点（甲府）
- 予報モデルの格子点
